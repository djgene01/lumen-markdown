# Changelog

## 1.0.0 — 2026-10-30

First release.

- WinUI 3 desktop shell on .NET 10, unpackaged x64.
- Open Markdown from picker, drag-and-drop or command line.
- Markdig rendering with tables, task lists, footnotes and front-matter; raw HTML escaped.
- RichEditBox editor with Markdown token highlighting, line-number gutter, find and go-to-line.
- Live WebView2 preview with debounced updates, scroll sync and light/dark themes.
- Save / Save As with encoding and line-ending preservation; dirty prompts.
- Recent files, window geometry, theme and layout persisted as JSON.
- 60-second draft autosave with recovery prompt.
- External-change detection with reload banner.
- 20 unit and integration tests for the core library.
